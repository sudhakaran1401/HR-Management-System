# Usability Testing

## Objective

Evaluate the usability of the HRMS by completing representative tasks across the major application modules and recording task completion, time taken, errors, and user feedback.

## Test Scope

The following representative tasks were tested:

- Login
- Dashboard navigation
- Employee management
- Attendance
- Leave
- Payroll
- Reports

## Usability Test Results

| Task | Completion | Time Taken | Errors | User Feedback |
|---|---|---:|---|---|
| Login | Pass | ≤ 20 sec | None | Easy to use |
| Dashboard Navigation | Pass | ≤ 20 sec | None | Navigation is clear |
| Employee Management | Pass | ≤ 20 sec | None | Easy to complete |
| Attendance | Pass | ≤ 20 sec | None | Simple and clear |
| Leave | Pass | ≤ 20 sec | None | Easy to understand |
| Payroll | Pass | ≤ 20 sec | None | Information is clear |
| Reports | Pass | ≤ 20 sec | None | Easy to access |

## Observations

- All tested tasks were completed successfully.
- No errors were encountered during the usability testing sessions.
- Each tested task was completed within 20 seconds.
- The navigation and major HRMS functions were straightforward to use.
- No significant usability difficulties were observed.

## User Feedback

The tested HRMS workflows were easy to understand and complete. Navigation was clear, forms and module functions were straightforward, and the required information could be accessed without significant difficulty.

## Conclusion

Usability testing was performed across login, dashboard navigation, employee management, attendance, leave, payroll, and reports. All tested tasks were completed successfully within 20 seconds, with no errors observed. Overall, the HRMS demonstrated good usability for the tested workflows.
